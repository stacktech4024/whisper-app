# Whisper App

A cross-platform mobile application designed to capture and transcribe speech using device-native capabilities. Built with Ionic Angular and Firebase.

## 🚀 Tech Stack

- **Framework:** Ionic 6 / Angular
- **Language:** TypeScript
- **UI styling:** HTML and SCSS (`src/global.scss`, `src/theme/variables.scss`)
- **Backend:** Firebase (Authentication, Firestore, Storage, Emulator Suite)
- **Mobile Runtime:** Capacitor
- **Testing:** Karma

## ✨ Features

- Speech-to-text transcription
- Cross-platform (iOS, Android, Web)
- Real-time data sync via Firebase
- Firebase Emulator support for local development

## 📋 Prerequisites

- Node.js (v16 or later)
- npm or yarn
- Angular CLI (`npm install -g @angular/cli`)
- Ionic CLI (`npm install -g @ionic/cli`)
